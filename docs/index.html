tern

A small, fast, minimalist terminal coding agent built for DeepSeek — also supporting OpenRouter, other cloud providers, local LLMs, and ACP agents.

v0.7.3 · single static binary · ~10ms startup · macOS · Linux · Windows · MIT

Install

curl -fsSL https://tern.disgusting.work/install.sh | sh

SHA-256 verified from GitHub Releases · update anytime with tern update · remove with tern uninstall

Built for daily flow

Calm two-pane TUI

Chat on the left, live inspector on the right with context/cache gauges, clickable sub-agent tabs, and right-click copy.

Parallel sub-agents

Explore, research, review, or edit concurrently with per-path write locks and one-click thread peeking.

Prefix-cache first

Append-only history, deterministic tool schemas, and proper DeepSeek V4 thinking passback keep cache hits high.

Steer & queue

Queue follow-ups while a turn runs, or press Ctrl+S to steer mid-flight without losing context.

Instant undo

Shadow-copy file checkpoints before every edit turn — roll back with /undo or tern undo, no git required.

Extensible & local

Skills, hooks, MCP servers (stdio & HTTP), folder extensions, plus --local for offline Ollama endpoints.
